/>This is a WIP educational game about the circulatory system. 
/>The idea is for players to play as a ghost that possesses different cells like red blood cells, white blood cells and platelets. 
/>They will then complete different missions that cover information on the circulatory system. 
/>The aim of this project is to create a game that helps students with studying.

Currently available:
- Start in the bone marrow and talk to the npcs by clicking on them
- Look at quests by clicking the quest icon, the other quest icon is a guide
- Travel through the tunnel by entering the vessel opening and inputting a code 
- Earn oxygen by answering questions in a quiz
- Deposit oxygen and food cells into tissue cells by dragging the oxygen and particles from the bloodstream to the tissue cells

**Since this is an educational game for studying, it is meant to revise already know content. 
/>Click the second quest icon for a guide with the answer key for the tunnel.

Upcoming:
- play as white blood cell to fight bacteria
- play as platelet to form blood clots
- control the heart to pump blood
